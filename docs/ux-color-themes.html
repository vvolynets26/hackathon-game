Theme Personality

"Cozy Blackout" Theme
Emotional Impact: Warm, cozy, comforting despite darkness
Best For: Casual gaming, cultural connection, emotional resonance
Visual Style: Dark atmosphere with warm light sources, balanced, professional game UI

Rationale: The dark blues/greys create the night/blackout atmosphere, while warm yellows/oranges from light sources provide visual warmth and coziness - the emotional core of the experience. The UI uses light colors for readability against dark backgrounds, with warm accents to maintain the cozy feeling even in interface elements.
